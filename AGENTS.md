# Yordan Bian's Portfolio Website

## Overview

Yordan's full-stack developer portfolio website.

## Technologies

- Frontend: React Router v7 app
- Styling: TailwindCSS
- CMS: Strapi v5
- Database: PostgreSQL

## Design

Display font: Satoshi
Theme: Light, minimalist, sharp corner, thin border, subtle shadow.

## Content

- Hero: Tall. Parallax + fade on scroll. Simple pattern background.
  - Eyebrow: PORTFOLIO / year
  - Title: Site owner's name
  - Subtitle: Role
  - Button: Download resume

- Sections: Slide in (GSAP)

- Skill and Project Cards: Elevate on hover.

- Skills
  - Card: Large icon, align vertical.
  - Mobile: 2 columns grid

- Experiences: Timeline
